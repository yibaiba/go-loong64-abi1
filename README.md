# LoongArch ABI 1.0 Go toolchains

Public releases of **ABI 1.0** Go builds for Kylin / UOS / Loongnix (`ld.so.1`, ELF Flags=`0x3`). These are **not** official [go.dev](https://go.dev/dl/) `linux-loong64` packages (those are ABI 2.0 and segfault on Kylin ABI 1.0).

Current: **go1.27.3** bootstrapped from Loongnix go1.27.1. See [Releases](https://github.com/yibaiba/go-loong64-abi1/releases).
